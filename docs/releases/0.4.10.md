# card-glint 0.4.10

This patch adds opt-in Magic calibration defaults without changing existing
callers' rendering behavior or requiring a new printing-style API version.

- Select automatic defaults, exact printing corrections, source colors, or a
  named compatible profile independently of frame selection and printed identity.
- Expose the selected frame's actual color and black-level coverage through the
  existing style results/options and a pure public calibration report.
- Use M21 as the initial provisional modern default. Transfer shared component
  corrections by pinned source identity and apply its outer-border target to
  native special-frame plates using their own stock selection. Preserve white
  and silver borders, colored textures, interior ink, artwork and layout.
- Keep unknown materials explicitly uncalibrated. Exact printing corrections
  take precedence in automatic mode; fallback coverage is never counted as a
  measured calibration of another printing.
- Reuse cached material preparation and isolate policy changes in face keys.
  No additional work runs during animated frames.

Validation covers policy precedence, serialization, invalid choices, unchanged
printing identity, independent historical ink/stock, special-frame asset mapping,
stock-pixel isolation, cached-face identity, and legacy native rendering replay.

The legacy native replay covers 84 cards across twelve sets (LEA, LEB, 2ED, 3ED,
4ED, MIR, TMP, M15, M19, M20, M21 and WAR): all are pixel-identical to 0.4.9 when
the new policy is omitted. Historical calibration receipts retain their original
hashes and scores through a hash-checked compatibility record.
